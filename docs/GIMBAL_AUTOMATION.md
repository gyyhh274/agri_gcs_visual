# 航点自动云台与前方 Y+ 标定

更新日期：2026-11-06。需配套 ly 上 `feat/gcs-dynamic-mission` 分支的新版 `multipoint`、任务网关和云台节点。启动模块、上传航线均不会触发起飞，也不会立刻转动云台。

## 现场坐标：前方 Y+、右侧 X+

按最新现场复测，默认采用 +90° 映射：**地图 X = −world Y，地图 Y = world X**。此前 −90° 设置下后退导致 Y 增大、右移导致 X 减小；本次翻转 180°，使前进对应 Y 增大、右移对应 X 增大。启动即可使用此方向，无需先做两点标定。

方向设置会保存到本机。重新打开应用或定位会话变化后继续使用已保存方向；新定位会话仍会清除坐标核对，需重新检查原点、航点和高度。只有明确选择“恢复 world 坐标”，才使用原始 X/Y 方向。

如果设备安装方向或现场方向发生变化，可在“标定前方 Y+”中记录起点、沿实际正前方直走至少 0.5 m，再点击“设为 Y+”。也可以点击“现场前 Y+ / 右 X+”恢复本现场的 +90° 设置。修改方向需要定位有效、飞机未解锁；落地后的任务降落锁定不妨碍修改显示方向。

原点不平移，Z 不变。显示坐标统一应用于地图、无人机位置、航点表和编辑框；保存文件、JSON 导入和任务协议仍使用原始 **world**。地图选点、拖动和表格编辑会反向转换，已有航点实际位置保持一致。不要把显示坐标直接写进 world JSON。

方向变化会关闭打开的航点编辑框并清除坐标核对。新增回归覆盖实际前进／右移方向、选点反向转换和应用重开后的设置保留。

## 配置到点自动转动和拍照

1. 启动飞行栈与 **云台控制** 模块；仅需识别时，YOLO 另行选择。
2. 在航点表点击 **编辑**，设置 **到点云台动作**：无动作、转到指定角度，或水平范围扫描。
3. 设置水平角／扫描起止角、俯仰角、转速档位、稳定等待和拍照选项，保存航点。
4. 上传航线并等待机载确认。起飞悬停、任务及云台执行器就绪后，再明确点击 **开始任务**。

| 参数 | 范围与含义 |
| --- | --- |
| 水平角 | −135° 到 +135°，向右为正；相对于云台安装基座，不随地图标定角旋转 |
| 俯仰角 | −90° 到 +25°，向下为负 |
| 扫描 | 先到起始水平角，再到终点；起始角必须小于终点角 |
| 转速档位 | 整数 1–100，限制 SDK 速度指令；不是 °/s，也不是飞行速度。建议先从 10–30 调试；实测很低档位可能不足以驱动小角度调整，执行器仍遵守所设上限并在未到位时报告超时 |
| 稳定等待 | 0–10 秒，目标到位后等待；随后再次检查姿态 |
| 拍照 | 定角／扫描最终姿态到位后拍照一次；等待相机反馈，不会在扫描途中连续拍照 |

执行顺序为：到达航点并稳定悬停 → 航点悬停时间 → 速度受限的云台转动 → 稳定等待 → 可选拍照 → 完成回执 → 下一航点。状态区显示转动、稳定、拍照和异常阶段。

无云台动作的旧航线保持原行为。旧网关未声明动作能力时，地面站拒绝上传带云台动作的航线，避免参数被忽略。飞行中只允许修改尚未执行的后续航点；正在执行的云台动作随当前点一起锁定。

## 手动拨杆调速

右侧 **拨杆转速** 为 1–100 SDK 档位，默认 30。满杆输出不超过该档位，小幅推杆按比例降低；松杆发送零速。该设置只影响手动拨杆，不改变角度滑条、回中或朝下的相机内置速度。航点自动动作使用每个航点单独配置的转速。

自动云台任务执行期间，地面站锁定手动执行器指令，并清理未发送的角度目标和执行器重试。断开任务遥测后仍保留已知的自动控制权，重连确认任务结束后解除，避免两条独立控制链互相覆盖。

## 异常处理与验证范围

机载以定位会话、任务、航点和动作 ID 关联回执；重复下发同一动作不会重复拍照。云台离线、动作超时、悬停条件失效或相机拍照反馈失败会结束当前任务并报告异常，不会直接计为完成。拍照结果未知时不自动补拍。返航、降落及任务终止会取消待执行云台动作。

地面站测试覆盖参数往返、非法参数拒绝、64 KiB 本地帧限制、手动调速及控制权切换、地图双向旋转、航点编辑与保存。联调使用独立 ROS master 和带 `gimbal-dry-run` 标记的模拟端点；没有触发真实起飞或执行真实航点，也没有以模拟结果代替相机实物到位与照片验收。

地面站本次完整 CTest 9 组通过；另行显式启用的真实 Qt／隔离 ROS 联调完成 2/2 航点，见[联调日志](gimbal-joint-2026-11-06.log)。执行器的 6 秒稳定等待也在旧重发间隔设为 12 秒时通过，验证租约刷新独立于旧配置。
