# 当前定位地图上的单点往返任务

开发分支：`codex/indoor-point-roundtrip`，基于地面站 `zjc-argc` 的 `c0ed01f`。机载对应仓库使用同名开发分支，基于 `08d4ff2`，仅在新工作目录开发。

## 操作

1. 等待真实建图 LIVE。打开地图右上角“往返任务”。
2. 机载任务栈、规划器、控制器就绪，人工起飞并稳定悬停后，点击“确认起始悬停点 R”。界面要求约两秒位置稳定、OFFBOARD、已解锁及机载空中状态检查通过，不发送起飞指令。
3. 默认目标高度使用刚记录的 R.z。可填写目标的 **world Z**；这不是自动推算的离地高度。
4. 点击“俯视图选择目标 P”，在地图点击 XY。3D 旋转、平移与缩放不会改变坐标计算；选点只支持俯视模式。地图显示 P/R 和参考连线，连线不是实际避障路径。
5. 设置目标悬停秒数，点击“上传往返任务”。发送完整 `[P, R]` 航点，不开始飞行。机载按占据地图、已观测空间和围栏预检。
6. 上传确认后，点击“开始执行”并确认。两段轨迹由机载 Diff-Planner 分别规划，结束后在 R 悬停，降落人工操作。

开始、终止都有独立确认。终止会停止任务与规划输出，不自动降落，也不能直接恢复该任务；观察机体并准备遥控器接管。

## 前提与边界

- 仅支持**本次持续定位会话**。不支持把旧 PCD 当作可导航地图，不支持重定位或任意非单位坐标变换。
- 当前机载 LIO -> EKF 配置为同一 world、零位置偏置。机载比较时间差不超过 50 ms 的 LIO/EKF 位姿：至少连续 10 组通过，位置差 <= 0.15 m、姿态差 <= 5 度且数据新鲜。差异超限或未收到规划器围栏证明时不放行。此检查不是自动外参标定。
- 地面站还核对本次点云会话、任务会话、真实数据标记和时间戳。地图/定位重启、来源切换或围栏变化后旧标点失效，必须重新确认 R 并上传。
- 机载需要按实际围网和顶网设置**已扣除机体及跟踪误差余量的可飞中心体积**。缺少边界时功能保持禁用，不猜测实验室尺寸。机载配置和测试见机载仓库 `docs/INDOOR_POINT_ROUNDTRIP.md`。
- 一键建图仍只启动传感器和定位。打开地面站、打开任务面板、地图点击、上传都不会自动启动飞行控制、解锁或起飞。

## 通信和异常

`GroundLink` 保留 protocol 1 只读兼容，并支持 protocol 2 的上传、开始、查询、终止。一次仅一项待确认请求，ACK 必须匹配 request_id；超时或断线显示结果未知，不自动重发开始。修改 P/Z 或重新记录 R 后必须重新上传，不能沿用旧任务确认。

任务本身由机载执行，短时 Wi-Fi 断开时，若机载定位/控制/规划状态正常，已有任务继续执行返回；地面站重连后只显示/查询状态，不自动开始、重新上传或采用旧标点。重开软件看到机载已有任务时，不自动取得其编辑/开始资格，终止必须再次明确确认。定位、坐标核对或规划/控制就绪条件失效时，任务执行器停止任务并锁定失败状态；不能把此行为当作所有异常下都能保证悬停。

任务完成不会触发自动降落。ROS 飞控失联动作和遥控器接管仍由原飞行控制链路负责，部署前需独立验证。

## 部署文件

任务网关通过专用隧道连接 `127.0.0.1:8765`：

- `deploy/install_task_tunnel.sh` 与 `deploy/agri-task-tunnel.service`。
- 使用独立的 `~/.ssh/agri_task_ed25519`，机载公钥仅允许转发 8765，不允许 shell。原地图密钥保持只转发 37262/37263。
- 复用已核验的 SSH 主机标识 `agri-onboard-pointcloud`；隧道跟随 `VideoStream/host`，不在代码中写密码。

正常运行会自动连接该本机任务端口；显式手动断开后不自动重连。演示/截图启动不主动连接任务网关。
